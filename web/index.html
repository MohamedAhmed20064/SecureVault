How it works
  1. A random AES-256 key is generated
  2. AES-GCM encrypts the message (any length)
  3. RSA-2048 encrypts only the AES key
  4. The receiver recovers the AES key with the RSA private key, then decrypts

    
Why
RSA alone is limited to about 190 bytes and is slow. AES alone needs a shared password. Together you get speed, any size, and safe key exchange.
